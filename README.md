# 🛡️ TruthTrace AI

**AI-Powered Digital Content Authenticity & Fraud Detection Platform**

TruthTrace AI is an intelligent web platform designed to verify the authenticity of digital content such as images, documents, payment receipts, and other digital files. It helps users identify manipulated, AI-generated, or forged content using Artificial Intelligence and modern web technologies.

---

## 📌 Overview

With the rapid rise of AI-generated content and digital fraud, verifying whether a file is genuine has become increasingly important.

TruthTrace AI aims to provide users with a simple and reliable platform to upload digital content and receive an authenticity analysis, helping reduce misinformation and fraud.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/TruthTrace-AI.git
```

### Move into Project

```bash
cd TruthTrace-AI
```

### Install Dependencies

```bash
npm install
```

### Create Environment File

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret
GEMINI_API_KEY=your_api_key
```

### Start Backend

```bash
npm run server
```

### Start Frontend

```bash
npm run client
```

### Run Both

```bash
npm run dev
```

## 📖 Workflow

1. User logs in.
2. Uploads an image or document.
3. The AI model analyzes the uploaded file.
4. Forgery and AI-generated content detection is performed.
5. An authenticity confidence score is generated.
6. A detailed verification report is displayed.
7. The report is saved in the user's verification history.
